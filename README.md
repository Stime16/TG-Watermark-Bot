# Telegram Watermark Bot

Telegram-бот для добавления текстовых водяных знаков на изображения. Позволяет отправить фотографию, указать текст и настроить внешний вид водяного знака прямо через Telegram.

## Возможности

- Добавление текстового водяного знака на изображение.
- Повторение водяного знака по всей площади фотографии.
- Настройка размера текста.
- Настройка прозрачности.
- Выбор цвета текста: белый, чёрный, красный, жёлтый и голубой.
- Настройка угла поворота.
- Сохранение пользовательских настроек в SQLite.
- Сброс настроек к значениям по умолчанию.
- Поддержка пользовательского TrueType-шрифта.

## Технологии

- **Python** — основной язык разработки.
- **python-telegram-bot** — взаимодействие с Telegram Bot API.
- **Pillow** — обработка изображений и нанесение водяных знаков.
- **SQLite** — хранение пользовательских настроек.
- **httpx** — HTTP-клиент, используемый библиотекой Telegram.

## Как работает бот

1. Пользователь отправляет боту фотографию.
2. Бот предлагает ввести текст водяного знака.
3. Изображение обрабатывается с учётом сохранённых настроек пользователя.
4. Готовое изображение отправляется обратно в чат.

## Команды

| Команда | Назначение |
|---|---|
| `/start` | Запуск бота и инструкция |
| `/settings` | Настройка внешнего вида водяного знака |
| `/resetsettings` | Сброс пользовательских настроек |
| `/cancel` | Отмена текущей операции |

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/telegram-watermark-bot.git
cd telegram-watermark-bot
```

Вместо `USERNAME` укажите свой GitHub-логин.

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Linux:

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте Telegram-бота через [@BotFather](https://t.me/BotFather) и получите токен.

Перед запуском задайте переменную окружения:

```bash
export BOT_TOKEN="YOUR_TELEGRAM_BOT_TOKEN"
```

Если требуется подключение через прокси:

```bash
export PROXY_URL="http://127.0.0.1:10809"
```

Если прокси не нужен:

```bash
export PROXY_URL=""
```

### 5. Запуск

```bash
python "bot (2).py"
```

После успешного запуска бот будет ожидать сообщения в Telegram.

## Хранение настроек

Для сохранения пользовательских параметров используется SQLite.

Для каждого пользователя хранятся:

- размер шрифта;
- прозрачность;
- цвет;
- позиция (поле предусмотрено в базе данных);
- угол поворота.
